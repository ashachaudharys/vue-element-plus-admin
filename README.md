# TKZC668后台

管理后台已升级为 `Vue 3 + TypeScript + Vite + Element Plus`。

## 启动

```bash
npm install
npm run dev
```

默认开发地址：

- `http://127.0.0.1:5174`

默认会把 `/api` 代理到：

- `http://127.0.0.1:18000`

## 页面

- `/login` 后台登录
- `/dashboard` 概览面板
- `/admins` 管理员账号
- `/users` 用户中心
- `/games` 运营开关 / 游戏管理 / 标签维护
- `/wallet-logs` 钱包日志
- `/providers` 供应商管理
- `/audit-logs` 审计日志
- `/observability` 可观测性说明
